# Flashcard App

**Study smarter.**

I built this because every flashcard app I tried was either bloated with features I didn't need, locked behind a subscription, or just ugly. I wanted something clean, fast, and actually pleasant to use when you're cramming the night before an exam.

This is that app.

## What It Does

Create decks, add cards, flip through them. That's the core. But the details matter:

- **Deck organisation** — group your cards by subject, topic, or whatever system works for your brain
- **Card flip animations** — smooth, satisfying, doesn't feel like a prototype
- **Progress tracking** — know which cards you're getting right and which ones are haunting you
- **Clean UI** — no clutter, no distractions, just you and the content you're trying to learn
- **Works on any screen** — fully responsive, use it on your phone between lectures or on your laptop at night

## Why Manual?

Because sometimes you need to write the card to remember the thing. The act of typing out a question and answer is already part of the learning. Auto-generation has its place but it's not what this is. This is for the student who wants to be intentional about what they're studying.

## Tech Stack

- **Framework:** React + Vite
- **Styling:** Tailwind CSS + shadcn/ui
- **Backend:** Node.js (Express)
- **Language:** TypeScript
- **Hosting:** Vercel

```bash

cd Flashcard-App
npm install
npm run dev
```
